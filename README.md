This repository contains three data mining and predictive analytics projects employing various machine learning techniques:

# Customer Personality Analysis - Clustering with K-Means
This project focuses on segmenting customers based on key factors, enabling businesses to tailor their products to the specific needs, behaviors, and concerns of diverse customer types. Additionally, it helps identify target customer segments for promoting specific products, reducing promotional costs. Detailed feature explanations and findings are compiled in the [project report](https://drive.google.com/file/d/10ir205z7B2KmsyG6g7Iyra8huXjZAXzg/view?usp=sharing) (in Bahasa Indonesia).

# Unlocking Insights: Exploring Heart Disease Prediction Through Logistic Regression and Machine Learning Techniques 
This study employs machine learning techniques to analyze factors influencing heart disease risk. A Logistic Regression model, well-suited for binary outcome prediction, is used to build a predictive framework. By integrating data-driven insights, the study aims to accurately identify individuals at higher risk of heart disease, facilitating early intervention and targeted prevention. Findings are detailed in the [project paper](https://drive.google.com/file/d/1V5P5apDEKlKTC59AUcvYLypK6ieSUMXZ/view?usp=sharing).

# Understanding Recurrent Heart Attack Risk: Insight from Data Analysis and Modelling
This project predicts the likelihood of heart attack recurrence in patients with a history of heart disease. It identifies critical factors contributing to risk and provides a framework for early intervention and personalized medical care. The analysis and results are documented in the [project paper](https://drive.google.com/file/d/1Brhwt17uvpiVnQxTIF_R313FxSfI9mMK/view?usp=sharing).
